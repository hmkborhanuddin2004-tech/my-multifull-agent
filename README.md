# 🤖 Multi-Agent Automation Ecosystem

An autonomous multi-agent cooperative framework written in **Python**, implementing supervisor-worker agent design patterns for complex business workflows, job marketing, talent hunting, and automated evaluation.

---

## 🌟 Key Architectures

- 👑 **Supervisor Agent (`supervisor.py`):** Central coordinator responsible for task decomposition, priority scheduling, and dispatching tasks to specialized subagents.
- 🎯 **Job Marketing Agent (`job_marketing_agent.py`):** Autonomous lead generation, outreach drafting, and marketing pipeline automation.
- 🏹 **Hunter Agent (`hunter_agent.py`):** Intelligent web scraper and data aggregator identifying market opportunities and business requirements.
- ⚖️ **Evaluator Agent (`evaluator_agent.py`):** Quality assurance and rubric grading agent reviewing outputs before final delivery.
- 🏆 **Hackathon Agent (`hackathon_agent.py`):** Rapid research, prototyping, and synthesis assistant.

---

## 🛠️ Tech Stack

- **Language:** Python 3.10+
- **Agent Orchestration:** Custom Supervisor-Worker Framework
- **Tools & Libraries:** Requests, Pydantic, Dotenv, Asyncio
- **Extensible Integration:** REST API & Telegram/Discord webhooks
